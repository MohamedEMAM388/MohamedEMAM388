## 📌 Featured Project

### 🗂️ [TaskManagement API](https://github.com/MohamedEMAM388/TaskManagement)

A RESTful API where users organize work into **projects → tasks → comments**, secured so users only manage what they own.

**Stack:** C# · ASP.NET Core (.NET 9) · EF Core · SQL Server · MediatR · FluentValidation · Hangfire · Swagger

**Design highlights**

- **CQRS with MediatR** and pipeline behaviors for logging and validation
- **Result pattern** for expected failures, with RFC 7807 problem-details responses
- **Task status workflow** enforced in the domain (`Todo → InProgress → Completed`)
- **Soft delete** with cascading, using EF Core global query filters
- **Refresh token rotation** with a Hangfire job that cleans expired tokens

```text
API  ──►  Application  ──►  Domain
 │             ▲
 └──► Infrastructure (EF Core, Identity, Repositories, Hangfire)
```
